**2026-11-24 にすべて実施済み**（9 章に結果）。バックアップ：`D:\hoby\pinball\pinball_backup_20261124`（Library／Temp／Logs は除く）。

## 1. 方針

1. **本編の 4 つのフォルダ（`Pinball/`、`PinballDodgeball/`、`PinballUI/`、`ControlsGuide/`）は、名前も場所も変えない。**
   Editor のツール 5 本がこの 4 つのパスを直に書いている（内訳の 7 章）。場所を変えると本編のコードを直す必要が出るので、今回は動かさない。
2. **フロントエンドで足すものは、すべて `PinballFrontend/` の中に置く。** 本編のフォルダには何も足さない。
3. **本編の外に散らばっているもの**（`Image/`、`Fonts/`、テンプレートの残り）だけを片づける。
4. **使っていないアセットは、まず `_Unused/` に移す。** すぐには消さない。ビルドして動くことを確かめてから消す。

## 5. シーンの置き場所と Build Settings

FE のシーンは、本編の `Scenes/` ではなく `PinballFrontend/Scenes/` に置く。FE で足すものを 1 か所にまとめ、本編のフォルダに手を入れないため。

登録の順番：

| 番号 | シーン | 備考 |
|---|---|---|
| 0 | `PinballFrontend/Scenes/FE_Title.unity` | 最初に開くシーン |
| 1 | `PinballFrontend/Scenes/FE_ModeSelect.unity` | |
| 2 | `Scenes/Pinball_VersusMode.unity` | 今は 0 番に登録されている |
| 3 | `Scenes/PinBall_DodgeMode.unity` | 今は登録されていない |

シーンを名前で読むか番号で読むかは、FE のコードを書くときに決める。名前で読むことにすれば、番号がずれても困らない。

## 6. asmdef について（今回は入れない）

- 入れると、本編とフロントエンドがはっきり分かれ、コンパイルも速くなる。
- ただ、本編の 4 フォルダにも asmdef を置く必要がある。PinballUI → Pinball の参照と、TMP・Input System への参照も書かなければならない。本編に手を入れることになるので、今回は入れない。
- 入れることになったら、`PinballFrontend` は `Pinball` と `PinballDodgeball` を参照する形にする（逆向きの参照は作らない）。

## 7. 進め方

1. **プロジェクトを丸ごとバックアップする。** このプロジェクトには git などのバージョン管理がない（`.git` が無い）。動かした後で戻せるように、先にフォルダごとコピーしておく。
2. Unity を開き、3 章の 1〜4 を Project ウィンドウで動かす。
3. 2 つのシーンを開いて、Missing（参照切れ）が出ていないか確かめる。Console にエラーが出ていないかも見る。
4. `PinballFrontend/` の下に、2 章の空のフォルダを作る。
5. Windows 向けにビルドして、対戦ルールが今までどおり起動することを確かめる。
6. 問題がなければ `_Unused/` を消す。

## 8. 決めてほしいこと

- **3 章の 1〜4 を動かしてよいか。** どれも本編のコードには影響しない。ただ、`Image/` の画像は ControlsGuide の持ち物に入れることになる。
- **`_Unused/` を経由するか、すぐに消すか。** 案では経由する。
- **FE のシーンの置き場所。** 案では `PinballFrontend/Scenes/`。本編と同じ `Scenes/` にまとめる手もある。
