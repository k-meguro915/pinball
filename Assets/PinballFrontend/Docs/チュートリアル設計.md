# チュートリアル設計（あそびかた）

作った日：2026-11-24　状態：**案**（まだコードは書いていない）
もとにした資料：[FE設計.md](FE設計.md)、[本編への相談_ドッジボールの操作.md](本編への相談_ドッジボールの操作.md)

## 0. 決まっていること（2026-11-24 の指示）

- 手順を追う形はやめる（長くなるため）。**説明を読みながら、自由に試し打ちできる画面**にする。
- **右半分 = 説明**：ルールと操作の説明。テキストと画像を使う。**ギミックの説明は省く**。
- **左半分 = 試し打ち**：自由に操作できる。**サーブは P1 から始める（固定）**。相手は、モード選択が VS CPU なら CPU、1 VS 1 なら P2（人）。
- **画面を分ける割合**は、一度目で見て確かめてから決める（それまでは半分ずつ。`FEConfig` で変えられるようにしておく）。

## 1. 画面

```
┌──────────────────────┬──────────────────────┐
│  左：試し打ち          │  右：説明              │
│                      │  ［ルール］［操作］［サーブ］…  ← タブ │
│   本編のシーンを       │  ・画像                │
│   そのまま動かす       │  ・テキスト             │
│   （サーブは P1 から） │                      │
│                      │  試合の様子（点数など）   │
│                      │  操作の案内（下の帯）     │
└──────────────────────┴──────────────────────┘
```

- 説明はタブ（ページ）に分ける。ページは切り替えるだけで、試し打ちは止めない。
- **ページの切り替え**：遊ぶ操作と重ならないボタンを使う。
  - パッド：十字キーの左右（どちらのルールでも、十字キーは遊ぶ操作に使っていない。移動は左スティック）
  - キーボード：Q／E（今の割り当てでは、どちらのプレイヤーも使っていない）
  - マウス：タブを押す
- **やめる**：Esc／パッドの Select → モード選択に戻る（ふつうの試合と同じ）。
- **この設定で試合をはじめる**：Enter／パッドの Start → モード選択で選んでいた設定で、ふつうの試合を始める（7 章の 3 で決める）。

## 2. 説明の中身

ギミック（ドッジボールのシュートポスト、ドロップターゲット、コースター、スピナー、加速レーン。対戦ルールのパワーショット、バンパーなど）は説明しない。

### 2.1 対戦ルール

| ページ | 中身 | 画像 |
|---|---|---|
| ルール | 相手のゴールに入れて 1 点。真ん中が山で、球は今いる側のゴールへ転がる。先に決めた点数を取った方の勝ち | `ControlsGuide_Rules`（今ある） |
| 操作 | フリッパー、サーブ、ルート切り替え、ブロッカーを動かす、キャッチ、跳ね返し。ボタン名は Input Actions から読んで出す（つないでいる機器に合わせる）。1 VS 1 のときは P1 と P2 を並べる | `ControlsGuide_Gamepad`（今ある。**7 章の 1 を参照**） |
| サーブ | 長押しで溜めて離すと発射。打つ前ならルートを切り替えられる。弱すぎて戻るとフォルト、2 回続くと相手に 1 点 | `ControlsGuide_Serve`（今ある。**7 章の 1 を参照**） |
| ブロッカー | 動かす、キャッチして投げ返す、跳ね返す。強い球が当たると HP が減り、0 でしばらくダウン | `ControlsGuide_Blocker`（今ある。**7 章の 1 を参照**） |

### 2.2 ドッジボール

| ページ | 中身 | 画像 |
|---|---|---|
| ルール | 相手の選手 3 人を全員アウトにしたら勝ち。相手の色の球に当たるとアウト。球の色 = いま誰の球か（白 = だれの球でもない）。アウトになった選手は外野へ。外野が投げた球で相手をアウトにすると戻ってくる | **無い**（7 章の 2） |
| 操作 | フリッパー、選手を動かす、サーブ、ルート切り替え、キャッチ（押している間）、投げる（離す）、ジャストキャッチ（球が来る直前に押すと速い球）。ボタン名は Input Actions から読む | 対戦ルールと同じパッドの絵を使えるかは、7 章の 1 しだい |
| サーブ | 試合の始めだけ。溜めて離すと発射、打つ前ならルートを切り替えられる。フォルトが 2 回続くとサーブが相手に移る | **無い**（7 章の 2） |

- 文は、本編の説明（`DBHud` のタイトル、`ControlsGuideData`、各スクリプトの説明）から、ギミックを除いて短くする。
- 文と画像は ScriptableObject（`FETutorialContent`）に入れて、ルールごとに 1 つ作る。あとで文を直すときにコードを触らなくてよいようにする。ボタン名は `{Flipper}`、`{Serve}` のような印を書いておき、実行時に Input Actions の名前に置き換える。

## 3. 試し打ちの台の作り方

本編のシーンをそのまま読み、FE が読み込んだ直後（Start の前）に準備する。今の `FESession`／Adapter と同じしくみ。

| すること | 対戦ルール | ドッジボール | 本編を直すか |
|---|---|---|---|
| 相手 | モード選択の設定のまま（VS CPU なら CPU とその強さ、1 VS 1 なら P2） | 同じ | 直さない（対戦ルールは ApplyRules が入ってから。それまでは本編シーンの値） |
| サーブは P1 から | 最初のサーブ番を決める口を足す（`firstServer` は今は private で、試合の始めにランダム） | `StartMatch()` は P1 → P2 → … と交互に始める。P2 から始まったら、もう一度 `StartMatch()` | **対戦ルールだけ数行直す** |
| カメラを左に | `Camera.main.rect = (0, 0, 割合, 1)` | 同じ | 直さない（どちらのカメラも LateUpdate で `cam.aspect` に合わせて台全体を映す） |
| HUD | 止める（7 章の 4） | 止める（7 章の 4） | 直さない |
| 始めの操作説明（F1） | 開かないようにする（`showOnStart = false`） | （無い） | 直さない |
| 試合が終わったら | すぐ `StartMatch()`（サーブはまた P1 から） | 同じ | 直さない |

- 対戦ルールのサーブ番は、点が入るたびに本編のルールどおり交代する（2 本ごと）。「P1 から」は、試合の始まりのこと。
- 対戦ルールの本編の直し方は、ApplyRules と合わせて 1 か所にする（例：`ApplyRules(mode, targetScore, cpuLevel, firstServer = -1)`。-1 なら今と同じくランダム）。

## 5. 作る順番

1. 土台：`StartTutorial`、`FETutorialBridge`、カメラを左に、HUD を止める、試合のやり直し、ドッジボールのサーブを P1 から。右は仮の文字だけ。両方のルールで、左に台が出て自由に遊べることを確かめる。
2. **ここで画面を分ける割合を目で見て決めてもらう。**
3. 対戦ルールの本編の直し（ApplyRules と最初のサーブ番）。
4. 右の説明の画面と、2 つの `FETutorialContent`（文・画像）。
5. モード選択の「あそびかた」ボタン、7 章で決めたこと。
6. Windows 向けにビルドして確かめる。

## 6. 気をつけること

- 左に寄せると、台は今より小さく映る（1920×1080 で半分なら、台を映す枠は 960×1080）。
- HUD を止めると、本編のメッセージ（サーブ番、フォルト、アウトなど）は出ない。要るものは右の「試合の様子」に出す。
- 右の説明はページを切り替えても試し打ちを止めない。読みながら遊ぶ形なので、説明は短くする。
