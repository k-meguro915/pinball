## 2. 作り方

### 2.1 分けるかどうか（本編）
- 対戦：`Pinball.SplitScreen`（static）。`Allowed`（はじめは true。FE のあそびかたが false にする）と、`Active`（今分けているか）を持つ。`Active` = `Allowed` かつ 1 VS 1（`MatchMode.Versus`）かつ タイトルでない。
- ドッジボール：`PinballDodgeball.DBSplitScreen`（同じ形。1 VS 1 = `Mode.Versus`）。

### 2.2 カメラ（本編：`CameraFit`、`DBCameraFit`）
- 分けるとき：今のカメラ（P1）の `rect` を左半分（0〜0.5）にし、子に 2 台目のカメラ（P2）を作って右半分（0.5〜1）に置く。2 台目は同じ設定を写し、真上から 180 度回す。
- 半分の画面（960×1080）に台をまるごと映す。HUD のパネルを置けるように、台を画面の内側（真ん中の線の側）に寄せ、外側を空ける。
- 分けないときは 2 台目を止め、`rect` を全体に戻す。

### 2.3 操作（本編：`PinballInput`、`DBInput`）
- 分けているときだけ、P2 のスティックの上下左右を逆にする（P2 の画面の向きで動く）。
- 分けているときだけ、P2 の LB／RB で動くフリッパーを入れ替える（P2 の画面の左のフリッパー = LB）。
- CPU の入力は変えない（分けるのは 1 VS 1 だけなので、CPU とは重ならない）。

### 2.4 HUD（本編：`PinballHud`、`DBHud`）
- 分けているときは、P2 のパネルを右下へ移す（P1 は左下のまま）。知らせ（真ん中の大きな文字）は、そのまま画面の真ん中に出す。
- ドッジボールの台の上の文字（サーブのルート、当たった所の知らせ）は、2 つのカメラそれぞれで位置を求めて 2 回描く。

### 2.5 FE
- `FETutorialBridge`：あそびかたの間は `SplitScreen.Allowed` と `DBSplitScreen.Allowed` を false にし、終わったら戻す。

## 3. 決めてほしいこと：台の上の文字（P2 の画面で逆さまになる）
台に貼った文字（対戦の「アウトレーン」などのレーンの名前、タイマー、POWER、ドッジボールの同じような文字）は、台と一緒に映るので、P2 の画面では逆さまに見える。

| 案 | 中身 | 手間 |
|---|---|---|
| A | まずは逆さまのまま出す。遊んでみて気になったら直す | なし |
| B | 分けているときは、台の上の「文字」だけを P2 の画面に映さない（光・矢印・ゲージなどの絵は残す）。P2 の画面では、文字の代わりに絵だけで見せる | 小さい（文字を別のレイヤーに移し、P2 のカメラに映さない） |
| C | P2 の画面用に、文字を P2 向きにした 2 組目を作る | 大きい（`BoardIndicators` 847 行と `DBBoardIndicators` を、2 組出せるように作り直す） |

おすすめは **B**。逆さまの文字は読めないので、映さないほうがよい。ただし P2 は、P1 の画面にだけ出る文字を見ることになる。

**決定（2026-11-27）：B**（P2 の画面に、台の上の文字を映さない）。

## 4.1 試し：自陣だけを映す（2026-11-27）
ユーザーの希望で、P1 と P2 のカメラがそれぞれ自陣側だけを映す写し方を足した。タイトルの「せってい」の「1 VS 1 の画面」で選ぶ（はじめは台全体。[FE設計.md](FE設計.md) の 18 章）。Editor では、試合中に **F2** でも切り替えられる（保存はしない。ビルドでは効かない）。

| | 台全体（`WholeBoard`） | 自陣だけ（`OwnHalf`） |
|---|---|---|
| 大きさ | 台がまるごと入る。外側の 36% を HUD 用に空ける | 台の幅いっぱい（大きく映る）。縦は、自分のゴールの端から、真ん中の線の先（台の半分の 20% 以上）まで |
| 位置 | 台を真ん中の線の側へ寄せる | 映す範囲の下の端を自分のゴールの端に合わせる |
| HUD | パネルは台の外 | 台の幅いっぱいなので、**パネルが台に重なる**（試してから決める） |

- 片方の画面（縦横比 0.89）だと、台の幅で大きさが決まる。対戦ルールでは真ん中の線の先まで約 4、ドッジボールでは約 3.6 の長さが見える（計算の目安）。
- 中身：`SplitScreen.ViewStyle`、`SplitScreen.View`、`OwnHalfReach`（0.2）。F2 は Editor だけで、`SplitScreen.Apply` の中で 1 フレームに 1 回読む。切り替えると Editor.log に「[Pinball] 画面分けの映し方：…」と出る。
- 決めること：どちらにするか。自陣だけにするなら、HUD のパネルの置き方（小さくする、半透明にする、など）。
