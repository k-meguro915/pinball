# 本編への相談：ドッジボールの操作を対戦ルールにそろえたい

日付：2026-11-24　相談する人：パッケージング担当（FE）
対象：`Assets/PinballDodgeball/Scripts/DBInput.cs`、`DBHud.cs`（ドッジボール）
状態：**決定・実施済み**（2026-11-24。結果は 6 章）

## 1. 何をしたいか

1 本のゲームにまとめると、ルールによって同じボタンの意味が変わってしまう。**対戦ルール（Pinball）の操作を正として**、ドッジボールの操作をそれにそろえたい。

## 2. 今の操作のちがい

### 対戦ルール（正）
入力は `PinballInput` が、Project-wide Actions（`Assets/InputSystem_Actions.inputactions`）の `P1`／`P2` マップから読む。パッドは、つないだ順に 1 台目 → P1、2 台目 → P2。

| アクション | パッド | 対戦ルールでの意味 |
|---|---|---|
| FlipperTop | LB | 上のフリッパー |
| FlipperBottom | RB | 下のフリッパー |
| Plunger | RB | サーブ（押して溜め、離して発射） |
| RouteToggle | LB | サーブのルート切り替え |
| BlockerCatch（無いので Plunger を使う） | RB | 押している間、ブロッカーが球をつかむ |
| BlockerBounce（無いので RouteToggle を使う） | LB | ブロッカーで跳ね返す |
| MoveBlockers | 左スティック | ブロッカーの列を動かす |
| （UI）BackToTitle（無い） | ― | 試合中にタイトルへ：**キーボードの Esc だけ** |

- **キーボードの割り当てはアセットに 1 つもない。** そのため、Input Actions が使える今の状態では、対戦ルールはキーボードでは遊べない（キーボード固定の操作は、Input Actions が無いときの予備）。
- RB は「下のフリッパー」「サーブ」「キャッチ」を、LB は「上のフリッパー」「ルート切り替え」「跳ね返し」を兼ねている。

### ドッジボール（今）
入力は `DBInput` が、キーボードとパッドを直接読む（Input Actions は使っていない）。

| 入力 | パッド | キーボード P1 | キーボード P2 | ドッジボールでの意味 |
|---|---|---|---|---|
| flipL | LB | Q | U | 左のフリッパー |
| flipR | RB | E | O | 右のフリッパー |
| b | **B（East）** | Space | H | サーブ（溜めて発射）、キャッチ（押している間）、外野が投げる、シュートポストが撃つ（ボタン操作のとき） |
| y | **Y（North）** | R | Y | サーブのルート切り替え |
| move | 左スティック／十字キー | WASD | IJKL | 選手を動かす。外野・シュートポストの向き、投げる向き |
| （UI）cancel | Select | Esc | Esc | 決着の後にタイトルへ |

## 3. そろえた後の案

**DBInput が、対戦ルールと同じ Input Actions（`P1`／`P2` マップ、同じアクション名）を読む**ようにする。こうすると、割り当てを変えたいときはアセット 1 か所を直すだけで、両方のルールに効く。

| ドッジボールの入力 | 読むアクション | パッド | 対戦ルールの同じボタン |
|---|---|---|---|
| flipL | FlipperTop | LB | 上のフリッパー |
| flipR | FlipperBottom | RB | 下のフリッパー |
| b | BlockerCatch（無ければ Plunger） | **RB** | サーブ・キャッチ |
| y | BlockerBounce（無ければ RouteToggle） | **LB** | ルート切り替え・跳ね返し |
| move | MoveBlockers | 左スティック | ブロッカーを動かす |

- パッドの割り当ても、対戦ルールと同じにする（1 台目 → P1、2 台目 → P2）。
- **対戦ルールと同じく、ボタンが重なる。** RB で「右のフリッパー」と「キャッチ／サーブ／投げる／撃つ」が同時に起きる。LB で「左のフリッパー」と「ルート切り替え」が同時に起きる。対戦ルールでも同じ重なり方をしているので、そろえるとこうなる。
  - ドッジボールでは、キャッチ（押している間）と右のフリッパーが同時に動くので、遊び心地が変わる。ここが一番大きな変化。
- VS CPU のとき、対戦ルールは「P1 は P2 側の操作（2 台目のパッドなど）でも動かせる」。ドッジボールも同じにするかは 5 章で決める。
- **DBHud の操作の表示**（「B：発射…」「Y：サーブのルート切り替え」など）も、RB／LB に合わせて直す。
- `PinballDodgeball` から `Pinball`（`PinballInput`）は参照しない。今の「ドッジボールは他のフォルダに依存しない」を保つため、DBInput の中で同じアセットを読む。

## 4. 直すファイル

| ファイル | 直すこと |
|---|---|
| `DBInput.cs` | `ReadHeld()` を、Input Actions（P1／P2）から読む形にする。パッドの割り当て（1 台目／2 台目）。アセットが無いときの予備のキーボード操作 |
| `DBHud.cs` | 操作の表示（`Key()` と、パネルの説明の文） |
| `DBGameManager.cs` | 直さない予定（`DBInputState` の中身は今と同じ） |
| `DBCpu.cs` | 直さない（CPU は `DBInputState` を直接作っている） |

## 5. 決めてほしいこと

1. **キーボード**：対戦ルールはキーボードの割り当てが無いので、そろえるとドッジボールもキーボードで遊べなくなる。
   - A（おすすめ）：Input Actions にキーボードの割り当てを足す。中身は対戦ルールの予備の配置と同じ（P1 = W／S／D・Space／A／TFGH、P2 = ↑／↓／←／→／IJKL）。対戦ルールもキーボードで遊べるようになる（対戦ルールの見た目や動きは変わらない）。
   - B：ドッジボールのキーボードは今のまま残す（パッドだけそろえる）。
   - C：キーボードはなし（パッドだけ）。
2. **VS CPU のとき、P2 側の操作でも P1 を動かせるようにするか**（対戦ルールと同じにするか）。
3. **試合中にタイトルへ戻る操作**：対戦ルールは Esc だけ（パッドでは戻れない）。FE は今、ドッジボールでだけパッドの Select でも戻れるようにしている。そろえるなら、どちらに合わせるか。
4. **だれが直すか**：本編の担当が直すか、FE 担当が直すか。

## 6. 決まったこと（2026-11-24）

| # | 決定 |
|---|---|
| 1 | キーボード：**A**。Input Actions の P1／P2 にキーボードの割り当てを足した（P1 = W／S／D・Space／A／TFGH、P2 = ↑／↓／←／→／IJKL）。対戦ルールもキーボードで遊べるようになる |
| 2 | VS CPU のとき P2 側の操作で P1 を動かす：**しない**（ドッジボールは P1 の操作だけ） |
| 3 | 試合中にタイトルへ戻る：**両方とも Esc＋パッドの Select**。対戦ルールの Select は FE（`FEVersusAdapter`）が読む。本編は直していない |
| 4 | 直す人：今は開発者が 1 人なので、FE 担当がそのまま直してよい。開発者が増えたら、あらためて知らせてもらう |

### 直したファイル
| ファイル | 内容 |
|---|---|
| `Assets/InputSystem_Actions.inputactions` | P1／P2 にキーボードの割り当てを足した（足しただけで、今あるパッドの割り当ては変えていない） |
| `Assets/PinballDodgeball/Scripts/DBInput.cs` | `ReadHeld()` を Input Actions（P1／P2）から読む形にした。パッドの割り当ては対戦ルールと同じ。ボタン名を返す `Label()` を足した。Input Actions が無いときの予備は、対戦ルールの予備と同じ配置。`ReadUI()`（タイトル・決着画面）は変えていない |
| `Assets/PinballDodgeball/Scripts/DBHud.cs` | 操作の表示を `DBInput.Label()` から読むようにした。本編のタイトル画面の説明文の「B」を「RB」に直した |
| `Assets/PinballFrontend/Scripts/FEVersusAdapter.cs` | 対戦ルールでも、パッドの Select で FE に戻る |

- 対戦ルールの PinballInput は、シーンを抜けるときに同じマップのパッドの割り当てを外す。DBInput は、外れていたら割り当て直すようにした。
- コンパイル：Editor の外で、本編を含む実行時のスクリプト 58 本をまとめてコンパイルし、エラー 0 件。Unity で両方のルールを遊んで、問題なかった（2026-11-24）。

### 気をつけること（遊んで確かめる）
- ドッジボールで RB を押すと、右のフリッパーとキャッチ（サーブ・投げる・撃つ）が同時に起きる。LB は左のフリッパーとルート切り替え。対戦ルールと同じ重なり方だが、ドッジボールではキャッチを押している間ずっと右のフリッパーが上がるので、遊び心地が変わる。
- 決着の後に戻る操作は、まだ少しちがう（対戦ルール = Esc・パッドの B・Select、ドッジボール = Esc・Select）。B で戻ると次の試合の操作と重なるので、ここはそのままにしてある。
